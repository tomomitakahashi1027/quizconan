# 名探偵コナン診断ゲーム

GitHub Pagesで動作する、HTML/CSS/JavaScriptだけの静的サイトです。

## ファイル

- `index.html` 画面構造
- `style.css` デザインとスマホ対応
- `script.js` 質問、診断、ランキング、共有機能
- `assets/pattern.svg` オリジナル背景パターン
- `.nojekyll` GitHub Pagesでそのまま配信するための空ファイル

## 公開方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダー内のファイルを、リポジトリのルートへアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branchを `main`、フォルダーを `/(root)` にして保存します。
6. Pages画面に表示される公開URLを開きます。

## 注意

- 非公式ファンメイドコンテンツです。
- 公式画像・ロゴ・音源は含めていません。
